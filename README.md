# monica_begnaud_portfolio
A Professional Project Repository 
### What is this?
This is the start of my professional portfolio. My website itself is a visual representation of the HTML and CSS skills I have learned throughout my Computing Applications course work, and also inlcudes examples of completed work and my skillset. 
### Why does it exist?
In an increasingly digital focused work atmosphere it is important to have a digital footprint that potential employeers can look at and get an understanding of what you have to offer. Visual examples speak louder than bullet points on a resume. 
### What tools did I use?
My website is hosted through GitHub pages. This not only makes it easily accessible for public viewing, but demonstrates my understanding of GitHub as a tool. The HTML and CSS coding was done in Visual Studio Code. This was the code editor that was used through my coursework so I was most familiar with it.
